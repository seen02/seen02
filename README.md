# 강신정 · Seen

Java와 Spring Boot로 백엔드를 개발합니다. AI 기능을 서비스에 연결하고 AWS 배포를 자동화해 왔으며, 기능을 만든 뒤에도 팀이 쉽게 운영하고 개선할 수 있는 구조를 고민합니다.

### 기술 스택

| 분야 | 프로젝트에서 사용한 기술 |
| --- | --- |
| **백엔드** | Java · Spring Boot · JPA · Querydsl · Python/FastAPI · Node.js |
| **데이터** | MySQL · Redis · PostgreSQL/pgvector |
| **AI 연동** | Gemini API · Ollama · Codex CLI |
| **인프라·배포** | AWS (EC2, RDS, S3) · Docker Compose · GitHub Actions |
